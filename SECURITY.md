# Sicherheitsrichtlinie

Die Sicherheit unserer Tools, Systeme und Daten hat für die **Franz Morat
Group** hohen Stellenwert. Wenn du eine Sicherheitslücke oder ein
Sicherheitsrisiko in einem Repository dieser Organisation entdeckst, hilf uns,
es verantwortungsvoll zu beheben.

## Eine Schwachstelle melden

**Bitte melde Sicherheitslücken niemals über ein öffentliches Issue, einen Pull
Request oder eine Diskussion.** So verhinderst du, dass Details bekannt werden,
bevor das Problem behoben ist.

Nutze stattdessen einen der folgenden vertraulichen Wege:

1. **GitHub Private Vulnerability Reporting** – sofern im betreffenden
   Repository aktiviert: Tab **Security → Report a vulnerability**.
2. **Per E-Mail (bevorzugt):**

     📞 +49 7657 88-170

     📞 +49 7657 88-376
   - **Allgemein / IT-Team:** itteamapplication@franz-morat.com

Bitte **keine** personenbezogenen oder vertraulichen Produktivdaten in die
Meldung aufnehmen.

## Was die Meldung enthalten sollte

- Betroffenes Repository / Tool und – falls bekannt – Version, Branch oder
  Commit
- Art der Schwachstelle und mögliche Auswirkung
- Schritte zur Reproduktion (Proof of Concept, falls vorhanden)
- Betroffene URLs, Endpunkte oder Komponenten
- Optional: Vorschlag zur Behebung

## Unser Vorgehen

- **Eingangsbestätigung:** in der Regel innerhalb von **3 Werktagen**.
- **Bewertung & Rückmeldung:** erste Einschätzung zeitnah nach Sichtung.
- **Behebung:** je nach Schweregrad und Aufwand; wir halten dich über den
  Fortschritt auf dem Laufenden.
- Wir bitten um eine angemessene Frist zur Behebung, bevor Details geteilt
  werden (Responsible Disclosure).

## Geltungsbereich

Diese Richtlinie gilt für die Repositories der GitHub-Organisation
**Franz Morat Group**. Für allgemeine IT-Sicherheitsvorfälle innerhalb des
Unternehmens wende dich an die IT bzw. an die im
[Verhaltenskodex](CODE_OF_CONDUCT.md) beschriebenen Melde- und
Compliance-Kanäle.

Wir danken allen, die zur Sicherheit unserer Systeme beitragen. Meldungen in
gutem Glauben werden begrüßt; **Vergeltungsmaßnahmen** gegen Meldende sind
ausgeschlossen.
